# Learning inbox

[Home](../README.md) · [Latest additions](../LATEST.md)

Capture a quick idea, useful link, question, or unfinished note here when you do not yet know where it belongs.

```bash
python3 scripts/new_note.py inbox "Investigate slow container builds"
```

Run this from the repository root. The helper creates a dated note here and adds an unchecked entry to `LATEST.md`.

When you have time:

1. Read the note and expand it with an example or takeaway.
2. Move it to the appropriate folder under `notes/` and give it a descriptive filename.
3. Update its link in `LATEST.md` and add it to the topic's `README.md`.
4. Mark the latest entry `[x]` once reviewed and update the note's status to `reviewed`.

Inbox notes are temporary; the topic folders are the long-term home.
